# Release Notes / 发布说明

## v0.1.0 — 首次版本 / Initial version

日期 / Date：2026-11-07

范围 / Scope：App Logo 设计工作流与双平台资源交付协议。App-logo design workflow and Android/iOS resource-delivery contract.

### 中文

首次整理完整的 App Logo 设计与交付工作流，从用户第一判断和品牌主张出发，经过风格探索与定稿，进入 Android、iOS 双平台图标资源交付。

**本版包含**

- 产品第一理解、第一感受、品牌主张和误读边界的沟通方法；复用已有确认，避免每轮重置定位。
- 六类真实风格参考，支持用户选择 1–3 种；已授权生图且未另定数量时，每种先生成一张。
- 同一品牌主张下分别构思内容。区分多风格内容探索、明确要求的同内容换画法和定点精修。
- 插画叙事通过角色、动作或生活场景表达主张；不默认把上一张拟物图加手绘纹理作为新方向。
- 原生 imagegen 优先的提示词协议、实际图像检查、小尺寸检查及迭代规则。
- 用户明确选定最终设计后，默认交付 Android、iOS 两套资源包；包括适用的平台资源、配置、商店用途文件、接入说明、清单与验证记录。
- 中英双语 README、发布说明与第三方素材说明。

**验证与边界**

- 已执行技能格式校验、Markdown 本地引用检查，以及发布准备包的结构和文件完整性检查；具体记录随交付提供。
- 新增的行为检查覆盖风格数量、插画误用、同内容对照、定稿打包、单平台限制、缺源文件和工具等情况；这些场景不等同于全部运行过的自动化测试。
- 本版本没有确认“花在哪”的最终 Logo，也没有实际生成该产品的 Android / iOS 发布图标包；没有完成工程构建、设备显示或商店审核验证。
- 按作者要求，发布准备包内置六类第三方 App 图标参考小图及场景补充图，支持离线查看；保留来源、观察版本和权利归属说明，不将其标为本项目原创素材。
- 未选定仓库级许可证，未执行 App 商店发布。

**版本与许可**

- 版本：`v0.1.0`。
- 许可证：待作者决定。
- 发布附件：本次准备的独立 skill ZIP；公众号对话素材包不作为公共发布附件。

### English

The initial version captures a complete app-logo workflow: establish the intended first impression and brand promise, explore styles, confirm a design, then prepare Android and iOS icon resources.

**Included**

- A product-judgment brief covering initial understanding, primary feeling, brand promise, and misinterpretations; confirmed decisions persist across iterations.
- Six visual-reference categories with a choice of 1–3 styles. Once generation is authorized, default to one concept per selected style unless specified otherwise.
- Independent content development under a shared brand promise, distinct from explicitly requested same-content restyling and targeted refinement.
- Narrative illustration expressed through characters, actions, or everyday scenes, rather than automatically adding hand-painted texture to a previous object rendering.
- Native-imagegen-first prompting, inspection of actual outputs, display-size checks, and focused iteration.
- Default Android and iOS resource packages after explicit final-design selection, with applicable platform assets, configuration, store artwork, integration steps, manifests, and validation records.
- Bilingual README, release notes, and third-party notices.

**Validation and limits**

- Skill-format checks, local Markdown-link checks, and release-preparation package integrity checks have been performed; records accompany the delivery.
- Acceptance scenarios cover style counts, narrative-illustration mistakes, controlled restyling, final packaging, single-platform scope, and missing sources/tools. They are not a claim that every automated behavioral test has run.
- No final logo for “花在哪” has been confirmed, and no actual Android/iOS release icon package for that product has been generated. Project builds, device display, and store review have not been validated.
- As requested by the author, the release-preparation package bundles local third-party app-icon thumbnails for the six categories and a supplementary scene reference. It supports offline viewing and preserves sources, observed versions, and rights-holder notices; these images are not presented as original project artwork.
- No repository-wide license has been selected. No app-store publication has been performed.

**Version and licensing**

- Version: `v0.1.0`.
- License: to be selected by the author.
- Release attachment: the prepared standalone skill ZIP. The editorial conversation-material package is not a public release attachment.
