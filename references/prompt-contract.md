# 提示词与迭代协议

在产品判断与风格已获用户确认后读取。参考 Phil 的模块组织和成品提示词思想，使用下列针对 App Logo 的独立契约；不继承海报专用的字体、网格、小字、白底或风格禁令。

## 编译前的输入

- 记录已确认的第一理解、第一感受、品牌主张与误读边界；不要求每一项都经过一次单独批准。已有确认直接沿用，仅对会实质改变结果的未知项提一个问题，其余标为合理制作假设或待验证项，不能补造“用户已确认”。
- 已确认或用户委托代选：1–3 种风格，以及用户明确指定保留的内容；未指定的母题不作为必须先确认的共同基线。
- 当前任务：统一品牌主张的多风格内容探索、同内容换画法或定点编辑；图片数量与用途。已授权生成且未另定数量时，每种所选风格先做一张，明确的数量要求优先。
- 真实输入：文字原文、目标图片、身份资产、风格参考。不存在的内容不编造。

用户给出形象画面后，先写“不可变关系”：人物在何处、在做什么、看向何处，哪些物件连接了这个故事。这比逐像素锁死构图更重要。

## 成品提示词槽位

用自然语言写成一条可独立执行的提示词。以下是结构说明，不是把空白模板交给生图工具：

1. **用途**：App 图标、独立品牌标、或场景概念；真实产品名仅在需要时出现。
2. **第一判断与情绪**：用一句话写目标，避免形容词堆叠。
3. **主体与关系**：明确物件、人物、动作、视线与核心场景；单一焦点不等于只有一个几何形状。
4. **视觉语言**：选定一种主导画法，明确轮廓、材质、空间、细节密度；不留“平涂/3D/手绘任选”等未决菜单。
5. **配色角色**：主色、背景、点睛色的关系，必要时提供已确认色值。预览和生产色值区分。
6. **构图**：主体占比、视觉重心、负空间，以及小尺寸下必须辨认的部分。
7. **文字**：是否有字；需要时精确写出用户提供原文。可先独立画标志再组合字标。
8. **约束**：仅列本轮真实风险；编辑时写保留项与改动项，不把所有历史否决当永久禁令。

英文美术指导与中文提示词都可按工具能力使用；不要假设中文指令会天然劣化结果。要渲染的文案与制作说明明确区分。

多张提示词分别保存时，产品主张和要保留的关系完整写入每条，避免“同上”。外部参考不直接复刻别人的图标或品牌轮廓。

## 对比方法

- **多风格内容探索（默认）**：固定品牌主张、第一判断和期望感受，为所选的 1–3 种风格分别构思适合的具体内容，不默认拿第一张图做其余方向的编辑目标。插画叙事通过角色、动作或场景表达主张，而不是只将拟物对象转成手绘。各方案可有不同内容，说明差异时不能声称它们是只改变画法的受控对照。
- **比较母题**：固定产品主张和期望感受，允许主体、动作与视觉策略不同。
- **同内容换画法（用户明确要求时）**：固定母题、关键关系和合理的主体大小，只改变渲染语言及其必要的光影。用户明确要求保留同一物件时，可以将其转为插画画法；不要借此擅自更换内容。
- **精修**：固定母题、画法、配色角色，每轮集中改一个影响最大的变量。
- **重做**：用户要求从零构思时，移除其否定的旧图参考，不把精修误报为重新设计；仍可采用用户指定的新风格参考，明确其只影响画法、不提供品牌身份。

## 示例：用户提出场景

已确认主张：“有规划，有实践，把握自己的花费和生活。”

用户画面：“一个成年女性躺在遮阳伞下，看大海。”

可编译的关系：女性在躺椅上放松地躺着，伞在上方遮阳，视线朝向有明确海平线的大海；情绪是主动安排生活后的从容。人物、躺姿、伞、看海关系固定，画法和细节预算待用户选择。

可以减少头发丝、衣褶、细浪、背景装饰；不能在没有用户同意时把人物删成圆点、把海改成代表自由的曲线。也不能声称这个场景已经被陌生人理解为消费工具。

## 工具执行

遵循当前宿主的图像工具参数和参考图规则。宿主 imagegen 可用时按其原生流程执行，提示词与路径可在生成后记录；不要让用户为内置工具提供 API key。明确选择外部提供方时才使用相应脚本与凭据流程。

只需要提示词时，交可复制的完整成品，不冒充已经生成图片。需要实际图像时，逐张调用工具并检查结果，不用 SVG/CSS 占位替代要求的栅格视觉。
