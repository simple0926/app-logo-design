# App Logo 设计 / App Logo Design

`app-logo-design` · v0.1.1 · [GitHub Releases](https://github.com/simple0926/app-logo-design/releases) · [发行说明 / Release notes](RELEASE_NOTES.md)

## 中文

从品牌主张与风格选择出发，设计应用图标，并准备 iOS 和 Android 图标交付。

提供风格参考、图标候选、反馈记录及平台工程交付约定。准备工程交付时，按用户选定目标核对可接入资源。

1. 从 [GitHub Releases](https://github.com/simple0926/app-logo-design/releases/tag/v0.1.1) 的附件下载 `app-logo-design-v0.1.1.zip`。
2. 解压后把 `app-logo-design/` 文件夹复制到 `~/.codex/skills/`。更新前先备份你自行改过的文件。
3. 在 Codex 里输入 `$app-logo-design`，附上你的目标、已有材料和交付要求。

第一判断、构建和设备显示须在具体项目中完成。

## English

Designs application icons from a product brief and visual direction through iOS and Android handoff.

Includes style references, icon directions, feedback guidance, and platform handoff rules. Engineering handoff checks the assets against the agreed target.

1. Download the attached `app-logo-design-v0.1.1.zip` from [GitHub Releases](https://github.com/simple0926/app-logo-design/releases/tag/v0.1.1).
2. Extract and copy the `app-logo-design/` folder to `~/.codex/skills/`. Back up any local customizations before updating.
3. In Codex, invoke `$app-logo-design` with your goal, available inputs, and expected deliverables.

Complete first-impression checks, builds, and device checks within each project.
